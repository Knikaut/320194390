# Память нашего края

Интерактивная карта исторических мест Костаная — школьный научный проект.

**Что внутри**
- 8 исторических мест на карте OpenStreetMap: факты с источниками, архивные и современные фото, «было / стало».
- Фильм «Город на карте»: рост Костаная на настоящей карте с 1879 года до наших дней, с событиями по годам и перемоткой по главам.
- «Добавить место»: посетитель фотографирует здание или памятное место, пишет о нём — и на карте появляется его зелёная метка.
- Аудиоэкскурсия (нейросетевой голос Piper «Ирина») с субтитрами и подсветкой фраз.
- «Машина времени» 1879–2054: история города по годам.
- Викторина «Знаток Костаная».
- «Узнать здание по фото» и подсказка «Вы рядом» по геолокации.
- QR-коды для табличек у зданий.

**Как устроено**
Сайт — файл `index.html`: фото и звук встроены в него. Рядом лежит папка `media` с фильмом
(`kostanay-1879-2020.mp4`, около 27 МБ) и его постером. Карта и QR-коды подгружаются из интернета
(Leaflet, qrcodejs, OpenStreetMap).

Места, которые добавляют посетители, хранятся в их собственном браузере (localStorage) — сервер и база данных
не нужны. В окне «Мои места» такие записи выгружаются в файл `moi-mesta-kostanay.json` и загружаются обратно:
так их можно передать руководителю проекта или перенести на другой компьютер.

**Публикация**
Репозиторий подключается к Vercel без настроек: Add New → Project → выбрать репозиторий → Deploy.
Чтобы обновить сайт, достаточно заменить `index.html` (и файлы в `media`, если меняется фильм).
