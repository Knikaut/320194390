# Память нашего края

Интерактивная карта исторических мест Костаная — школьный научный проект.

**Что внутри**
- 8 исторических мест на карте OpenStreetMap: факты с источниками, архивные и современные фото, «было / стало».
- Аудиоэкскурсия (нейросетевой голос Piper «Ирина») с субтитрами и подсветкой фраз.
- «Машина времени» 1879–2054: история города по годам.
- Викторина «Знаток Костаная».
- «Узнать здание по фото» и подсказка «Вы рядом» по геолокации.
- QR-коды для табличек у зданий.

**Как устроено**
Весь сайт — один файл `index.html`: фото и звук встроены в него. Карта и QR-коды подгружаются из интернета (Leaflet, qrcodejs, OpenStreetMap).

**Публикация**
Репозиторий подключается к Vercel без настроек: Add New → Project → выбрать репозиторий → Deploy.
Чтобы обновить сайт, достаточно заменить `index.html`.
